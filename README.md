# rclone-drive

A personal Google OAuth client used with [rclone](https://rclone.org/) to move files
between its owner's own computer and its owner's own Google Drive.

This repository contains no code. It exists to provide the **homepage URL** and
**privacy policy URL** that Google requires before an OAuth app can be moved out of
"Testing" publishing status.

- [Privacy Policy](PRIVACY.md)

## What the client does

It is used from the command line, on one machine, by one person, to upload and download
that person's own files. Nothing runs on a server, and no one else can use the client —
it is not distributed and it is not offered as a service.
